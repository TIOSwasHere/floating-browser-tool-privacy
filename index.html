Privacy Policy

Floating Browser Tool · Effective August 19, 2026

Overview

Floating Browser Tool does not collect, transmit, sell, or share personal information. The app has no user accounts, analytics, advertising, or network service.

Screen content

The app displays a region that you select from an existing desktop window on the same Windows device. Selected screen content is not uploaded, recorded, or stored by Floating Browser Tool.

Local settings

The app stores only a local preference indicating whether introductory instructions should be shown. This preference stays on your device and can be removed by deleting the app’s local settings.

Contact

For privacy questions, use the support contact listed on the Floating Browser Tool Microsoft Store page.

Changes to this policy

If this policy changes, the updated version will be published on this page with a revised effective date.
